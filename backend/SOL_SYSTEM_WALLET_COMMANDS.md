# Команды для работы с системными кошельками SOL

## Описание
Созданы команды для мониторинга и проверки балансов системных кошельков SOL-Solana.

## Доступные команды

### 1. Проверка конкретного кошелька
```bash
python manage.py check_system_wallet_balance --currency SOL
```

**Опции:**
- `--currency` - символ валюты (по умолчанию SOL)
- `--network` - сеть для проверки
- `--notes` - примечание для лога
- `--show-details` - показать детальную информацию
- `--last-n` - количество последних записей для показа (по умолчанию 5)

**Примеры:**
```bash
# Базовая проверка SOL
python manage.py check_system_wallet_balance --currency SOL

# Проверка с деталями
python manage.py check_system_wallet_balance --currency SOL --show-details --last-n 10

# Проверка с кастомным примечанием
python manage.py check_system_wallet_balance --currency SOL --notes "Еженедельная проверка"
```

### 2. Проверка всех системных кошельков
```bash
python manage.py check_all_system_wallets
```

**Опции:**
- `--network` - проверить только указанную сеть
- `--skip-zero` - пропустить кошельки с нулевым балансом
- `--log-balances` - логировать балансы в SystemWalletBalanceLog

**Примеры:**
```bash
# Проверка всех кошельков
python manage.py check_all_system_wallets

# Проверка только SOL кошельков
python manage.py check_all_system_wallets --network SOL

# Проверка с логированием и пропуском нулевых
python manage.py check_all_system_wallets --log-balances --skip-zero
```

## Что показывают команды

### check_system_wallet_balance
- Информация о валюте и сети
- Системный адрес кошелька
- Баланс в блокчейне и БД
- Сравнение балансов (синхронизированы ли)
- Последние записи в логе
- Статистика по типам транзакций (с --show-details)

### check_all_system_wallets
- Проверка всех активных валют
- Сравнение балансов блокчейна и БД
- Выявление проблем синхронизации
- Список кошельков с балансом > 0
- Итоговая статистика

## Интерпретация результатов

### Статусы синхронизации:
- **✓ Синхронизирован** - балансы в блокчейне и БД совпадают
- **⚠ Блокчейн больше** - в блокчейне больше средств (возможно, не учтены депозиты)
- **⚠ БД больше** - в БД больше средств (возможно, не учтены выводы)
- **⚠ Не найден в БД** - системный кошелек отсутствует в базе данных

### Типы транзакций в логах:
- **Deposit** - депозит на системный кошелек
- **Consolidation** - консолидация с пользовательского кошелька
- **Withdrawal** - вывод средств с системного кошелька
- **Manual Check** - ручная проверка баланса
- **System Update** - системное обновление

## Рекомендации по использованию

### Ежедневная проверка:
```bash
python manage.py check_all_system_wallets --network SOL
```

### Еженедельная детальная проверка:
```bash
python manage.py check_system_wallet_balance --currency SOL --show-details --last-n 20
```

### После проблемных операций:
```bash
python manage.py check_system_wallet_balance --currency SOL --notes "После проблемной транзакции"
```

## Автоматическое логирование

Баланс системного кошелька SOL автоматически логируется при:
- ✅ Обнаружении депозита
- ✅ Консолидации средств
- ✅ Выводе средств
- ✅ Подтверждении транзакций

## Просмотр логов в админке

1. Перейти в Django Admin
2. Выбрать "System Wallet Balance Logs"
3. Использовать фильтры:
   - По валюте (SOL)
   - По типу транзакции
   - По дате
4. Экспортировать данные в CSV при необходимости

## Устранение проблем

### Если баланс в БД больше чем в блокчейне:
1. Проверить логи выводов средств
2. Убедиться, что все выводы подтверждены
3. Синхронизировать баланс БД с блокчейном

### Если баланс в блокчейне больше чем в БД:
1. Проверить логи депозитов
2. Убедиться, что все депозиты учтены
3. Обновить баланс в БД

### Если системный кошелек не найден в БД:
1. Проверить настройки SystemWalletAddress
2. Убедиться, что UserWallet с is_system_wallet=True существует
3. Создать недостающие записи через админку
