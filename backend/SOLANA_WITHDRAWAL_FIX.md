# Решение проблемы с выводом Solana

## Проблема
При списании средств Solana крипта не доходит до кошелька. Средства списываются с баланса пользователя, но транзакция в блокчейне не проходит.

## Возможные причины

1. **Недостаток средств на системном кошельке** - самая частая причина
2. **Отсутствие или неправильный приватный ключ системного кошелька**
3. **Проблемы с подключением к Solana RPC**
4. **Ошибки в логике обработки транзакций**

## Диагностика

### Шаг 1: Проверка системного кошелька
```bash
cd backend
python manage.py check_solana_system_wallet
```

Эта команда покажет:
- Найдена ли валюта SOL в базе
- Существует ли системный кошелёк
- Установлен ли приватный ключ
- Баланс кошелька в базе и блокчейне
- Количество ожидающих выводов

### Шаг 2: Проверка логов
Посмотрите логи Django/Celery на наличие ошибок:
```bash
# В логах ищите сообщения с [process_withdrawal] и [send_transaction]
grep -i "solana\|process_withdrawal\|send_transaction" /path/to/logs/
```

## Решение проблем

### 1. Настройка системного кошелька

Если системный кошелёк не настроен:
```bash
# Создание/исправление системного кошелька
python manage.py fix_solana_issues --private-key="ВАШ_ПРИВАТНЫЙ_КЛЮЧ"
```

Поддерживаемые форматы приватного ключа:
- **Hex** (128 символов): `abcd1234efgh5678...`
- **JSON массив**: `[251,34,123,...]`  
- **Base58** (редко используется)

### 2. Пополнение системного кошелька

Если недостаточно средств:

**Способ 1: Реальное пополнение**
1. Отправьте SOL на адрес системного кошелька
2. Дождитесь подтверждения транзакции
3. Проверьте баланс: `python manage.py check_solana_system_wallet`

**Способ 2: Для тестирования**
```bash
# Добавить баланс в базу данных (только для тестов!)
python manage.py fix_solana_issues --add-balance="1.0"
```

### 3. Тестирование отправки

Протестируйте отправку транзакции:
```bash
# Тест без отправки
python manage.py test_solana_send --to-address="АДРЕС_ПОЛУЧАТЕЛЯ" --dry-run

# Реальная отправка (малая сумма)
python manage.py test_solana_send --to-address="АДРЕС_ПОЛУЧАТЕЛЯ" --amount="0.001"
```

### 4. Обработка застрявших выводов

Если есть ожидающие выводы:
```bash
# Запуск обработки всех ожидающих выводов
python manage.py shell -c "from crypto.tasks import process_pending_withdrawals; process_pending_withdrawals()"

# Или обработка конкретного вывода
python manage.py shell -c "from crypto.tasks import process_withdrawal; process_withdrawal.delay(TRANSFER_ID)"
```

## Улучшения в коде

Внесены следующие улучшения:

### 1. Улучшенная диагностика в `solana.py`:
- Проверка баланса системного кошелька перед отправкой
- Расчёт минимально необходимой суммы с учётом комиссий
- Подробное логирование всех этапов
- Увеличенные таймауты подтверждения
- Дополнительная проверка транзакции через 10 секунд

### 2. Улучшенная обработка в `tasks.py`:
- Раздельная проверка существования кошелька и приватного ключа
- Специальная проверка баланса для SOL с запасом на комиссии
- Подробное логирование процесса

### 3. Инструменты диагностики:
- `check_solana_system_wallet` - проверка состояния
- `fix_solana_issues` - автоматическое исправление
- `test_solana_send` - тестирование отправки

## Профилактика

1. **Мониторинг баланса**: Настройте уведомления при низком балансе системного кошелька
2. **Регулярные проверки**: Запускайте диагностику еженедельно
3. **Логирование**: Включите подробное логирование для Solana операций
4. **Тестирование**: Периодически тестируйте отправку малых сумм

## Контакты техподдержки

При сохранении проблем:
1. Запустите полную диагностику: `python manage.py check_solana_system_wallet`
2. Соберите логи за последние 24 часа
3. Проверьте статус Solana сети: https://status.solana.com/
4. Обратитесь к разработчикам с результатами диагностики
