# Отслеживание баланса системного кошелька SOL

## Описание
Добавлена функциональность автоматического отслеживания баланса системного кошелька SOL-Solana в базе данных после каждой транзакции.

## Что было реализовано

### 1. Новая модель `SystemWalletBalanceLog`
- **Назначение**: Логирует баланс системного кошелька после каждой транзакции
- **Поля**:
  - `currency` - валюта (SOL)
  - `system_address` - адрес системного кошелька
  - `blockchain_balance` - баланс в блокчейне
  - `database_balance` - баланс в БД (для сравнения)
  - `transaction_type` - тип транзакции (deposit, consolidation, withdrawal, manual_check, system_update)
  - `related_transaction` - связанная транзакция
  - `notes` - примечания
  - `created_at` - время создания записи

### 2. Автоматическое логирование
Баланс системного кошелька логируется автоматически в следующих случаях:

#### Депозиты (SOL)
- После обнаружения депозита на системный кошелек
- Записывается баланс после зачисления средств

#### Консолидация (SOL)
- После отправки консолидации с пользовательского кошелька
- После подтверждения консолидации в блокчейне
- Записывается баланс до и после операции

#### Выводы средств (SOL)
- После отправки вывода на внешний адрес
- После подтверждения вывода в блокчейне
- Записывается баланс до и после операции

### 3. Админ-интерфейс
Добавлен админ-класс `SystemWalletBalanceLogAdmin` с функциями:
- **Просмотр истории**: Все записи с фильтрацией по валюте, типу транзакции, дате
- **Сравнение балансов**: Показывает разность между блокчейном и БД
- **Экспорт в CSV**: Выгрузка данных для анализа
- **Ссылки на транзакции**: Прямые ссылки на связанные транзакции
- **Защита от редактирования**: Запрет на создание/изменение записей через админку

### 4. Команда для ручной проверки
```bash
python manage.py check_system_wallet_balance --currency SOL --notes "Ручная проверка"
```

## Использование

### Просмотр в админке
1. Перейти в админку Django
2. Выбрать раздел "System Wallet Balance Logs"
3. Использовать фильтры для поиска нужных записей
4. Экспортировать данные при необходимости

### Программное использование
```python
from crypto.models import SystemWalletBalanceLog

# Логирование баланса
SystemWalletBalanceLog.log_system_wallet_balance(
    currency=sol_currency,
    system_address="system_wallet_address",
    blockchain_balance=Decimal("100.5"),
    transaction_type="manual_check",
    notes="Ручная проверка баланса"
)

# Получение последних записей
recent_logs = SystemWalletBalanceLog.objects.filter(
    currency=sol_currency
).order_by('-created_at')[:10]
```

## Преимущества

1. **Полная прозрачность**: Видно все изменения баланса системного кошелька
2. **Аудит**: Полная история операций с временными метками
3. **Мониторинг**: Возможность отслеживания расхождений между блокчейном и БД
4. **Отладка**: Помогает в диагностике проблем с балансами
5. **Аналитика**: Данные для анализа операций и комиссий

## Технические детали

- Логирование происходит только для SOL-Solana
- Все операции логируются автоматически без дополнительного кода
- Записи защищены от случайного изменения
- Оптимизированные индексы для быстрого поиска
- Поддержка экспорта данных

## Мониторинг

Рекомендуется периодически проверять:
1. Разность между балансами в блокчейне и БД
2. Частоту операций и их типы
3. Необычные изменения баланса
4. Ошибки логирования (записываются в лог)
