# Криптообменник (Backend)

Бэкенд приложения для обмена криптовалют, созданный с использованием Django REST Framework.

## Установка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте окружение:
   - Windows: `venv\Scripts\activate`
   - Linux/Mac: `source venv/bin/activate`
4. Установите зависимости: `pip install -r requirements.txt`
5. Создайте файл `.env` на основе примера `env.example`
6. Примените миграции: `python manage.py migrate`

## Запуск сервера

Для запуска сервера разработки:

```bash
python manage.py runserver
```

Для запуска сервера с поддержкой кодировки и корректной работой с PostgreSQL:

```bash
python manage_direct.py runserver
```

## Структура проекта

- `core/` - основные настройки Django проекта
- `accounts/` - приложение для управления пользователями
- `crypto/` - приложение для работы с криптовалютами
- `transactions/` - приложение для обработки транзакций
- `scripts/` - утилиты для работы с базой данных

## Утилиты для работы с базой данных

В проекте есть набор скриптов для упрощения разработки и тестирования:

### Быстрый доступ к утилитам (из корня проекта)

- `python check_db.py [-v]` - проверка соединения с базой данных
- `python direct_db.py "SQL_ЗАПРОС"` - выполнение SQL-запроса
- `python users_create.py [-c COUNT] [-f]` - создание тестовых пользователей
- `python balance_update.py` - обновление балансов кошельков пользователей

Для получения подробной информации о каждой утилите запустите скрипт с флагом `--help`.

### Подробная документация

Полная документация по всем скриптам доступна в файле [scripts/README_SCRIPTS.md](scripts/README_SCRIPTS.md)

## Особенности работы с кодировкой

Проект настроен для корректной работы с кириллицей в Windows и PostgreSQL:

1. Установка локали `Russian_Russia.1251` для правильной работы с кириллицей
2. Явное указание параметров кодировки при подключении к базе данных: `client_encoding=UTF8`
3. Патчи для psycopg2 для корректной работы с UTF-8
