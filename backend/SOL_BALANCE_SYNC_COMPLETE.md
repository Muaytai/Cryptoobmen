# Автоматическая синхронизация баланса системного кошелька SOL

## Описание
Реализована полная система автоматической синхронизации баланса системного кошелька SOL-Solana в базе данных после каждой транзакции.

## ✅ Что реализовано

### 1. Автоматическая синхронизация в задачах
Баланс системного кошелька SOL автоматически синхронизируется в БД после:

#### Депозиты
- ✅ После обнаружения депозита на системный кошелек
- ✅ Баланс в БД обновляется до актуального значения из блокчейна

#### Консолидация
- ✅ После отправки консолидации с пользовательского кошелька
- ✅ После подтверждения консолидации в блокчейне
- ✅ Баланс обновляется на каждом этапе

#### Выводы средств
- ✅ После отправки вывода на внешний адрес
- ✅ После подтверждения вывода в блокчейне
- ✅ Баланс обновляется на каждом этапе

### 2. Улучшенный метод логирования
Метод `SystemWalletBalanceLog.log_system_wallet_balance()` теперь:
- ✅ Автоматически синхронизирует баланс в БД
- ✅ Логирует изменения с отметкой о синхронизации
- ✅ Обрабатывает ошибки синхронизации
- ✅ Обновляет `available_balance` с учетом `locked_balance`

### 3. Команды управления

#### Проверка баланса с синхронизацией
```bash
python manage.py check_system_wallet_balance --currency SOL
```
- Автоматически синхронизирует при расхождениях
- Показывает статус синхронизации

#### Проверка всех кошельков
```bash
python manage.py check_all_system_wallets --network SOL --log-balances
```
- Синхронизирует проблемные кошельки
- Логирует все изменения

#### Принудительная синхронизация
```bash
python manage.py sync_system_wallet_balance --currency SOL
```
- Принудительно синхронизирует баланс
- Поддерживает режим просмотра (`--dry-run`)

### Автоматическая синхронизация
- Обновляет `UserWallet.balance` до значения из блокчейна
- Пересчитывает `available_balance = balance - locked_balance`
- Логирует все изменения с отметкой о синхронизации
- Обрабатывает ошибки без прерывания основной логики

### Умная синхронизация
- Синхронизирует только при расхождениях балансов
- Поддерживает принудительную синхронизацию
- Предотвращает лишние операции при совпадающих балансах

### Статусы в логах
- `Synced: True` - баланс был синхронизирован
- `Synced: False` - синхронизация не требовалась
