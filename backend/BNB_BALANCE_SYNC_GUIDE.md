# Руководство по синхронизации баланса BNB кошелька

## Проблема
Баланс системного кошелька BNB в админке Django (0.21900000 TBNB) не соответствует балансу в MetaMask (0.2201 TBNB).

## Решение

### Вариант 1: Автоматическая синхронизация через команду

1. **Проверить текущее состояние:**
```bash
cd backend
python manage.py sync_bnb_balance
```

2. **Синхронизировать баланс:**
```bash
python manage.py sync_bnb_balance --update
```

### Вариант 2: Проверка конкретного адреса

Если нужно проверить баланс конкретного адреса (например, из MetaMask):

```bash
cd backend
python manage.py sync_bnb_balance --address 0xeA6BFd33720eCEBB96FB7FD1Bf5daCceF89
```

### Вариант 3: Использование простого скрипта

```bash
cd backend
python check_metamask_balance.py 0xeA6BFd33720eCEBB96FB7FD1Bf5daCceF89
```

## Что происходит при синхронизации

1. Команда получает реальный баланс из BNB Smart Chain Testnet
2. Сравнивает его с балансом в базе данных
3. При использовании флага `--update` обновляет баланс в БД до реального значения
4. Логирует изменения для аудита

## Проверка результата

После синхронизации проверьте баланс в админке Django:
1. Перейдите в Crypto > Wallets
2. Найдите "System Wallet - BNB"
3. Убедитесь, что баланс соответствует MetaMask

## Примечания

- Команда работает с BNB Smart Chain Testnet
- Все изменения логируются
- Можно запускать безопасно - без флага `--update` команда только проверяет баланс
- При необходимости можно сбросить баланс командой `python manage.py fix_system_wallet_balance --currency BNB --network BEP20 --reset-balance`

## Устранение неполадок

Если команда не работает:

1. Убедитесь, что виртуальное окружение активировано
2. Проверьте настройки BSC в `settings.py`
3. Убедитесь, что API ключ BSCScan настроен
4. Проверьте подключение к интернету
