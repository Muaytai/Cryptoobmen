# Руководство по удалению в админке

## Новые возможности удаления

### 🗑️ Удаление транзакций (`/admin/transactions/transaction/`)

#### Индивидуальное удаление:
- **Кнопка "🗑️ Удалить"** в каждой строке списка транзакций
- Доступна только **суперпользователям**
- Подтверждение через JavaScript alert
- Каскадное удаление связанных объектов (депозиты, выводы, обмены)

#### Массовое удаление:
- **"🗑️ Удалить выбранные транзакции"** в Actions
- Показывает информацию о связанных объектах перед удалением
- Подробная статистика удаленных объектов

#### Работа с дубликатами:
- **"🔍 Найти дубликаты транзакций"** - поиск по `tx_hash`
- **"🗑️ Удалить дубликаты транзакций"** - оставляет самую старую транзакцию

### 🗑️ Удаление кошельков (`/admin/crypto/userwallet/`)

#### Индивидуальное удаление:
- **Кнопка "🗑️ Удалить"** в каждой строке списка кошельков
- Доступна только **суперпользователям**
- Подтверждение с указанием валюты и пользователя

#### Массовое удаление:
- **"🗑️ Удалить выбранные кошельки"** в Actions
- **ПРЕДУПРЕЖДЕНИЕ** о кошельках с ненулевым балансом
- Показывает общую сумму средств перед удалением

## Безопасность

### Ограничения доступа:
```python
def has_delete_permission(self, request, obj=None):
    # Только суперпользователи
    return request.user.is_superuser
```

### Подтверждения:
- **JavaScript confirm** для индивидуального удаления
- **Детальная информация** о связанных объектах
- **Предупреждения** о балансах и важных данных

### Логирование:
- Все действия удаления логируются в Django admin log
- Сообщения об успешных и неудачных операциях
- Подробная статистика удаленных объектов

## Примеры использования

### Удаление дублирующихся транзакций:
1. Перейти в `/admin/transactions/transaction/`
2. Выбрать Action **"🔍 Найти дубликаты транзакций"**
3. Просмотреть найденные дубликаты
4. Выбрать Action **"🗑️ Удалить дубликаты транзакций"**
5. Подтвердить удаление

### Очистка тестовых данных:
1. Отфильтровать транзакции по нужным критериям
2. Выбрать транзакции через чекбоксы
3. Выбрать Action **"🗑️ Удалить выбранные транзакции"**
4. Проверить список связанных объектов
5. Подтвердить удаление

### Удаление пустых кошельков:
1. Перейти в `/admin/crypto/userwallet/`
2. Отфильтровать кошельки с `balance = 0`
3. Выбрать кошельки для удаления
4. Выбрать Action **"🗑️ Удалить выбранные кошельки"**
5. Подтвердить удаление

## ⚠️ ВАЖНЫЕ ПРЕДУПРЕЖДЕНИЯ

### Необратимость:
- **ВСЕ УДАЛЕНИЯ НЕОБРАТИМЫ**
- Нет функции восстановления
- Рекомендуется делать резервные копии БД перед массовыми удалениями

### Связанные объекты:
- При удалении транзакции удаляются связанные депозиты/выводы/обмены
- При удалении кошелька могут быть затронуты балансы пользователей
- Проверяйте зависимости перед удалением

### Финансовые риски:
- Удаление кошельков с балансом может привести к потере средств
- Удаление активных транзакций может нарушить финансовую отчетность
- **ВСЕГДА** проверяйте балансы и статусы перед удалением

## Технические детали

### Cascading Delete:
```python
# При удалении Transaction автоматически удаляются:
- Связанные Deposit объекты
- Связанные Withdrawal объекты  
- Связанные Exchange объекты
- Связанные Transfer объекты
```

### Методы удаления:
- `delete_selected_transactions()` - массовое удаление транзакций
- `delete_duplicate_transactions()` - удаление дубликатов
- `delete_selected_wallets()` - массовое удаление кошельков
- `delete_button()` - индивидуальные кнопки удаления

### Доступ к request:
```python
def changelist_view(self, request, extra_context=None):
    self._current_request = request
    return super().changelist_view(request, extra_context)
```
