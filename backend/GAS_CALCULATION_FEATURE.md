# Функциональность расчета газа для депозитов и выводов

## Обзор

Реализована функциональность расчета и отображения информации о газе для валют без мемо при депозитах и выводах. Это позволяет пользователям видеть точную стоимость газа, которая будет списана при консолидации депозитов и при выводе средств.

**ВАЖНО**: 
- При депозитах: баланс пользователей увеличивается на сумму депозита минус предполагаемая стоимость газа при консолидации
- При выводах: с баланса пользователя списывается сумма вывода + комиссия платформы + стоимость газа

## Изменения в коде

### 1. Новый модуль gas_calculation.py

#### Добавлен модуль для расчета предполагаемой стоимости газа
- `calculate_estimated_gas_cost()` - рассчитывает предполагаемую стоимость газа
- `calculate_net_deposit_amount()` - рассчитывает чистую сумму депозита с учетом газа
- `get_deposit_info_with_gas()` - получает полную информацию о депозите
- `calculate_withdrawal_gas_cost()` - рассчитывает стоимость газа для вывода
- `calculate_max_withdrawal_amount()` - рассчитывает максимальную сумму вывода с учетом газа
- `calculate_withdrawal_total_cost()` - рассчитывает общую стоимость вывода (сумма + газ + комиссия)

#### Поддерживаемые методы расчета:
- **Smart calculation**: для валют с `get_max_sendable_amount` (POL)
- **Estimated calculation**: для валют с `estimate_gas_cost` (ETH)
- **Fixed reserve**: fallback к фиксированным значениям

### 2. DepositService (crypto/services_deposit.py)

#### Обновлен метод `get_deposit_info`
- Теперь возвращает 4 значения вместо 3: `(address, memo, qr_code, gas_info)`
- Для валют с мемо `gas_info = None`
- Для валют без мемо `gas_info` содержит информацию о газе

#### Добавлен метод `_calculate_gas_info`
- Рассчитывает информацию о газе для валют без мемо
- Поддерживает три метода расчета:
  - **Smart calculation**: для валют с методом `get_max_sendable_amount` (например, POL)
  - **Estimated calculation**: для валют с методом `estimate_gas_cost` (например, ETH)
  - **Fixed reserve**: fallback к фиксированным значениям из `tasks_consolidation.py`

### 2. DepositInfoView (crypto/views_deposit.py)

#### Обновлен API endpoint `/crypto/deposit-info/`
- Добавлена поддержка нового формата ответа от `DepositService`
- В ответе API добавлено поле `gas_info` для валют без мемо
- Обеспечена обратная совместимость со старым форматом

### 3. WithdrawalService (transactions/services.py)

#### Обновлен метод `create_withdrawal_request`
- Теперь рассчитывает общую стоимость вывода (сумма + газ + комиссия платформы)
- Проверяет баланс с учетом стоимости газа
- В транзакции записывается только комиссия платформы (газ списывается отдельно)

#### Добавлены новые API endpoints в WithdrawalViewSet
- `POST /api/transactions/withdrawals/max-amount/` - получает максимальную сумму вывода с учетом газа
- `POST /api/transactions/withdrawals/calculate-cost/` - рассчитывает стоимость вывода (сумма + газ + комиссия)

### 4. Логика зачисления депозитов (crypto/tasks.py)

#### Модифицирована логика зачисления депозитов
- **Для валют с мемо**: зачисляется полная сумма депозита (газ не нужен)
- **Для валют без мемо**: зачисляется чистая сумма (депозит минус предполагаемый газ)
- Добавлено подробное логирование процесса расчета газа
- В транзакции записывается чистая сумма и стоимость газа

#### Обновлены места зачисления:
- Обработка депозитов с мемо (строки 300-320)
- Батч-обработка депозитов без мемо (строки 479-511)
- Обработка XRP депозитов (строки 615-632)

### 5. Логика вывода средств (crypto/tasks.py)

#### Модифицирована функция `process_withdrawal`
- Рассчитывает стоимость газа для вывода
- Блокирует средства на балансе пользователя (сумма + комиссия + газ)
- При подтверждении списывает все заблокированные средства

#### Модифицирована функция `check_withdrawal_confirmation`
- При подтверждении вывода списывает сумму + комиссию + газ
- Комиссия платформы начисляется на внутренний кошелек
- Газ просто списывается как стоимость транзакции

### 6. Задачи консолидации (crypto/tasks.py)

#### Обновлена функция `process_consolidation_for_wallet`
- Теперь возвращает 4 значения: `(success, tx_hash, amount_sent, gas_cost)`
- Рассчитывает точную стоимость газа для каждой валюты
- Записывает реальную стоимость газа в поле `fee` транзакции

#### Обновлена задача `process_pending_deposits`
- Обрабатывает новое возвращаемое значение с информацией о газе
- Записывает реальную стоимость газа в базу данных

### 4. Подтверждение консолидации (crypto/tasks_consolidation.py)

#### Обновлена логика списания комиссий
- Теперь списывает только реальную стоимость газа
- Добавлено логирование для отслеживания баланса пользователя

## Структура ответа API

### Для валют с мемо (XRP, BNB)
```json
{
    "address": "system_address_123",
    "memo": "123456",
    "currency_symbol": "XRP",
    "network": "XRP",
    "qr_code": "data:image/png;base64,..."
}
```

### Для валют без мемо (POL, ETH, BTC)
```json
{
    "address": "user_address_456",
    "memo": null,
    "currency_symbol": "POL",
    "network": "Polygon",
    "qr_code": "data:image/png;base64,...",
    "gas_info": {
        "estimated_gas_cost": "0.01",
        "current_balance": "1.0",
        "max_sendable_after_gas": "0.99",
        "currency_symbol": "POL",
        "calculation_method": "smart"
    }
}
```

## Поля gas_info

- `estimated_gas_cost`: Оцененная стоимость газа в основной валюте
- `current_balance`: Текущий баланс адреса (только для smart calculation)
- `max_sendable_after_gas`: Максимальная сумма, которую можно отправить после вычета газа (только для smart calculation)
- `currency_symbol`: Символ валюты
- `calculation_method`: Метод расчета ("smart", "estimated", "fixed_reserve")

## Методы расчета газа

### 1. Smart Calculation (POL)
- Использует метод `get_max_sendable_amount` из блокчейн сервиса
- Рассчитывает точную стоимость газа: `balance - max_sendable`
- Показывает текущий баланс и максимально отправляемую сумму

### 2. Estimated Calculation (ETH)
- Использует метод `estimate_gas_cost` из блокчейн сервиса
- Оценивает стоимость газа на основе тестовой транзакции
- Менее точный, но работает для большинства EVM-совместимых сетей

### 3. Fixed Reserve (Fallback)
- Использует фиксированные значения из `get_gas_reserve()`
- Применяется когда другие методы недоступны
- Значения настраиваются в `tasks_consolidation.py`

## Логика зачисления депозитов

### Для валют с мемо (XRP, BNB)
1. **Получение депозита**: Пользователь отправляет средства на системный адрес с мемо
2. **Зачисление**: На баланс пользователя зачисляется полная сумма депозита
3. **Газ**: Газ не нужен, так как средства уже на системном адресе

### Для валют без мемо (POL, ETH, BTC)
1. **Получение депозита**: Пользователь отправляет средства на свой уникальный адрес
2. **Расчет газа**: Рассчитывается предполагаемая стоимость газа при консолидации
3. **Зачисление**: На баланс пользователя зачисляется чистая сумма (депозит - газ)
4. **Консолидация**: При консолидации списывается только реальная стоимость газа

## Логика вывода средств

### Для всех валют
1. **Создание запроса**: Пользователь указывает сумму и адрес получателя
2. **Расчет стоимости**: Рассчитывается общая стоимость (сумма + комиссия платформы + газ)
3. **Проверка баланса**: Проверяется, что на балансе достаточно средств
4. **Блокировка средств**: Средства блокируются на балансе пользователя
5. **Отправка в сеть**: Средства отправляются с системного кошелька
6. **Подтверждение**: При подтверждении списываются заблокированные средства
7. **Начисление комиссии**: Комиссия платформы начисляется на внутренний кошелек

## Логика консолидации

1. **Проверка баланса**: Проверяется баланс в блокчейне
2. **Расчет газа**: Рассчитывается точная стоимость газа
3. **Отправка**: Отправляется `max_sendable_amount` на системный кошелек
4. **Запись транзакции**: В БД записывается транзакция с реальной стоимостью газа
5. **Списание газа**: При подтверждении консолидации списывается только газ

## Преимущества

1. **Корректный баланс**: Баланс пользователей рассчитывается с учетом газа с самого начала
2. **Прозрачность**: Пользователи видят точную стоимость газа при депозитах и выводах
3. **Точность**: Используется реальная стоимость газа, а не фиксированные значения
4. **Гибкость**: Поддерживаются разные методы расчета для разных валют
5. **Разделение комиссий**: Четко разделены комиссия платформы и стоимость газа
6. **API для фронтенда**: Новые endpoints для расчета максимальной суммы вывода и стоимости
7. **Обратная совместимость**: Старый код продолжает работать
8. **Логирование**: Подробное логирование для отладки
9. **Предотвращение ошибок**: Малые депозиты (меньше газа) не зачисляются на баланс

3. Или настройте фиксированный резерв в `get_gas_reserve()`
