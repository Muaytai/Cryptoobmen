Подробное описание работы Backend
🏗️ Архитектура Backend
    Backend построен на Django 5.2.3 с использованием Django REST Framework для создания API. 
    Это полнофункциональная платформа для обмена криптовалют с модульной архитектурой.
📦 Основные компоненты
    1. Приложение accounts - Управление пользователями
Модели:
    User - расширенная модель пользователя с полями:
    email (основной идентификатор)  
    phone_number, avatar, is_verified
    kyc_verified, full_name, date_of_birth, address (KYC данные)
    has_2fa - двухфакторная аутентификация
    notify_via_email/telegram - настройки уведомлений
    last_login_ip - безопасность
    UserProfile - дополнительный профиль пользователя
    UserDocument - документы для KYC верификации
Функциональность:
    Регистрация/авторизация через email
    Интеграция с социальными сетями (Google, Yandex)
    KYC верификация
    Двухфакторная аутентификация
    Управление профилем
2. Приложение crypto - Работа с криптовалютами
Ключевые модели:
    Cryptocurrency - информация о валютах:
    Поддержка крипто и фиатных валют
    Сетевые параметры (ERC-20, TRC-20, Bitcoin)
    Комиссии платформы (0.2% по умолчанию)
    Минимальные/максимальные суммы обмена
    Требования к MEMO/Destination Tag
    UserWallet - кошельки пользователей:
    Балансы: общий, доступный, заблокированный
    Адреса для пополнения
    Системные кошельки (для администраторов)
    Зашифрованные приватные ключи
    ExchangePair - пары для обмена:
    Настройка комиссий для конкретных пар
    Лимиты сумм обмена
    Активность/неактивность пар
    ExchangeOrder - ордера на обмен:
    Статусы: pending, executed, canceled, failed
    Курсы обмена и комиссии
    Время создания и выполнения
    SystemWalletAddress - системные адреса для пополнения
    UserDepositMemo - уникальные MEMO для пользователей
    CommissionWallet - кошельки для накопления комиссий
    API Endpoints:
3. Приложение transactions - Обработка транзакций
Модели:
    Transaction - основная модель всех транзакций:
    Типы: deposit, withdrawal, exchange, transfer, fee
    Статусы: pending, awaiting_confirmation, processing, completed, failed, cancelled, refunded
    Сетевая информация (tx_hash, block_number)
    IP адреса и заметки
Exchange - детали обменов:
    От какой валюты к какой
    Суммы и курсы
    Комиссии
    Deposit - депозиты:
    Подтверждения транзакций
    Адреса кошельков
Withdrawal - выводы средств:
    Подтверждение через email и 2FA
    Модерация администратором
    Возможность возврата средств
    Transfer - внутренние переводы
    Review - отзывы пользователей
�� Асинхронные задачи (Celery)
Основные задачи:
    check_blockchain_deposits() - проверка новых депозитов:
    Сканирование блокчейнов каждые 30 секунд
    Обработка транзакций с MEMO
    Автоматическое зачисление средств
    process_withdrawal() - обработка выводов:
    Проверка балансов
    Отправка транзакций в блокчейн
    Обновление статусов
    process_pending_withdrawals() - обработка ожидающих выводов
    process_pending_deposits() - обработка ожидающих депозитов
🔗 Интеграция с блокчейнами
Поддерживаемые сети:
    Bitcoin (через Blockcypher API)
    Ethereum (ERC-20 токены)
    TRON (TRC-20 токены)

🚀 Процесс работы системы
1. Регистрация пользователя:
    Создание аккаунта через email
    KYC верификация (опционально)
    Создание кошельков для всех валют
2. Пополнение:
    Пользователь получает адрес + MEMO
    Система сканирует блокчейн каждые 30 сек
    Автоматическое зачисление при обнаружении транзакции
3. Обмен валют:
    Пользователь выбирает пару и сумму
    Система рассчитывает курс и комиссию
    Создается ордер на обмен
    Автоматическое выполнение при достаточном балансе
4. Вывод средств:
    Пользователь указывает адрес
    Подтверждение через email + 2FA
    Модерация администратором
    Отправка в блокчейн
