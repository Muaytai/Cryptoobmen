# Инструкция по исправлению проблемы с заблокированными SOL

## 🚨 Проблема
На экране отображается сообщение "Заблокировано: 0.02200000 SOL", хотя в базе данных заблокированных средств нет.

## 🔧 Решение

### Шаг 1: Обновите страницу
1. Нажмите **F5** или **Ctrl+R** для обновления страницы
2. Если не помогло, нажмите **Ctrl+Shift+R** для принудительного обновления

### Шаг 2: Очистите кэш браузера
1. Откройте консоль браузера (**F12** → **Console**)
2. Скопируйте и вставьте следующий код:

```javascript
// Полная очистка кэша
localStorage.clear();
sessionStorage.clear();
if ('caches' in window) {
  caches.keys().then(names => names.forEach(name => caches.delete(name)));
}
window.location.reload(true);
```

3. Нажмите **Enter** для выполнения

### Шаг 3: Проверьте отладочную информацию
После обновления страницы в блоке заблокированных средств появится отладочная информация:
- `locked_balance: "0.02200000"` - исходное значение
- `Тип: string` - тип данных
- `parseFloat: 0.022` - преобразованное значение

### Шаг 4: Нажмите "Обновить данные"
В блоке заблокированных средств нажмите кнопку **"Обновить данные"** - это принудительно обновит данные с сервера.

## 🔍 Что происходит
Проблема в том, что:
1. **В базе данных нет заблокированных средств** (все показывают 0.00000000)
2. **Фронтенд кэширует старые данные** или получает их из другого источника
3. **React не обновляет состояние** корректно

## ✅ Ожидаемый результат
После выполнения всех шагов сообщение "Заблокировано: 0.02200000 SOL" должно исчезнуть, так как в базе данных действительно нет заблокированных средств.

## 🆘 Если проблема остается
Если после всех шагов сообщение все еще отображается, проверьте консоль браузера на наличие ошибок и сообщите о них разработчику.
