# Анализ и план развития проекта криптообменника

## Общая информация

Проект представляет собой криптообменник, разрабатываемый с использованием Django REST Framework для бэкенда и Next.js (версия 15, с TypeScript) для фронтенда. Проект нацелен на создание простого и интуитивно понятного сервиса для новичков, по аналогии с упрощенной версией Binance.

## Реализованный функционал ✅ [СДЕЛАНО]

### Бэкенд (Django REST Framework)

1.  **Управление пользователями и Аутентификация:**
    *   Полный цикл регистрации, аутентификации (JWT), подтверждения email и сброса пароля.
    *   Управление профилями и основа для KYC.

2.  **Управление криптовалютами и рыночными данными:**
    *   Ведение списка доступных криптовалют (крипто и фиат).
    *   **✅ [НОВОЕ] Оптимизированный механизм получения цен:** Создан эффективный эндпоинт (`/api/crypto/prices/latest/`) для получения актуальных курсов сразу для нескольких валют (например, `?vs_currencies=usd,eur,rub`).
    *   **✅ [НОВОЕ] Автоматическое обновление курсов:** Реализована management-команда (`update_prices`) для регулярного обновления цен с внешних сервисов (CoinGecko), что обеспечивает их актуальность.
    *   Сигналы для автоматического создания кошельков новым пользователям.

3.  **Финансовые операции:**
    *   Управление пользовательскими кошельками.
    *   Просмотр балансов, включая общий баланс в USD (эндпоинт `/api/crypto/wallets/balance/`).
    *   Функционал простого обмена валют.
    *   Пополнение счета с карты.

4.  **Управление транзакциями и инвестициями:**
    *   Ведение истории транзакций.
    *   Базовый функционал инвестиционных планов.

### Фронтенд (Next.js + TypeScript)

1.  **Пользовательский интерфейс и UX:**
    *   Стабильные и отлаженные страницы регистрации, входа, профиля.
    *   Унифицированы все API-запросы через общий клиент, работающий с HttpOnly cookies.
    *   Исправлены ключевые проблемы с аутентификацией и доступом к защищенным разделам.

2.  **Страница "Мои кошельки":**
    *   **✅ [НОВОЕ] Динамическое отображение баланса:** Реализован выпадающий список для просмотра общего баланса и баланса каждого кошелька в разных валютах (USD, EUR, RUB, BYN).
    *   **✅ [НОВОЕ] "Живое" обновление:** Данные на странице автоматически обновляются каждые 30 секунд и при возвращении на вкладку, обеспечивая актуальность информации без перезагрузки страницы.
    *   **✅ [НОВОЕ] Улучшенная надежность:** Исправлены ошибки, связанные с отсутствием иконок валют и другими проблемами рендеринга.

3.  **Финансовый функционал (интерфейс):**
    *   Отлажены и стабилизированы страницы пополнения, вывода, обмена и инвестиций.

## Путь пользователя (User Flow) 🚶‍♂️

Это описание того, как типичный пользователь взаимодействует с реализованным на данный момент функционалом.

1.  **Регистрация и вход:**
    *   Пользователь заходит на сайт, нажимает "Регистрация".
    *   Вводит email и пароль, после чего получает письмо для подтверждения.
    *   Переходит по ссылке из письма, его аккаунт активируется.
    *   Возвращается на сайт и входит в систему, используя свои данные.

2.  **Знакомство с кошельком:**
    *   После входа пользователь переходит в раздел "Мои кошельки".
    *   Он видит общий баланс своего портфеля. С помощью выпадающего списка он может моментально посмотреть эквивалент этой суммы в рублях, евро или другой доступной валюте.
    *   Ниже отображается список его кошельков (например, Bitcoin, Ethereum, Tether и т.д.).
    *   Для каждого кошелька он видит баланс в родной валюте (например, `0.005 BTC`) и его эквивалент в выбранной для отображения валюте (например, `≈ 350.50 USD`).
    *   Пока пользователь находится на странице, балансы незаметно обновляются в фоновом режиме.

3.  **Пополнение счета:**
    *   В карточке нужного кошелька (например, Tether) пользователь нажимает кнопку "Пополнить".
    *   Он переходит на страницу пополнения, где вводит сумму в фиатной валюте (например, 10000 RUB), которую хочет внести.
    *   Система показывает, сколько криптовалюты (USDT) он получит.
    *   Далее следует процесс, эмулирующий оплату картой.

4.  **Обмен валют:**
    *   В карточке кошелька (например, Bitcoin) пользователь нажимает "Обменять".
    *   На странице обмена он видит, что отдает BTC, и выбирает, что хочет получить (например, ETH).
    *   Система показывает ему текущий курс и итоговую сумму в ETH. После подтверждения происходит обмен.

5.  **Вывод средств:**
    *   В карточке кошелька пользователь нажимает "Вывести".
    *   Он указывает сумму для вывода и адрес внешнего кошелька.
    *   После подтверждения создается заявка на вывод.
